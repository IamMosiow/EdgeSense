# EdgeSense

An end-to-end embedded AI platform for real-time sensor acquisition,
signal processing, anomaly detection, and edge inference.

## Project Goal

Build a complete system that can:

1. Acquire real-world sensor data using an STM32.
2. Transfer and store the acquired data.
3. Process and analyze the data using Python.
4. Train machine-learning models for anomaly detection.
5. Optimize the model for embedded deployment.
6. Run inference directly on the STM32 in real time.
